# Java Rule-Based Chatbot

A simple rule-based chatbot developed in Java using core programming concepts.

## Project Overview

This project is a simple rule-based chatbot that interacts with users through predefined responses.

It was developed as **Project 1 of my AI Engineering Internship at Decode**.

The project focuses on applying Java fundamentals and basic programming logic to build a functional chatbot.

## Features

* Responds to predefined user queries
* Handles greetings and common questions
* Provides help responses
* Handles unknown queries with fallback responses
* Supports exit commands
* Maintains continuous conversation using a loop
* Processes user input using lowercase conversion and trimming

## Technologies Used

* Java
* IntelliJ IDEA

## Java Concepts Applied

* HashMap
* Set
* Scanner
* While loop
* Conditional statements
* String methods
* User input handling
* Decision-making logic

## How It Works

The chatbot takes input from the user, processes it, and provides a predefined response.

```text
User Input
    ↓
Input Processing
    ↓
Check Predefined Responses
    ↓
Response Found?
   ↙       ↘
 Yes        No
 ↓          ↓
Response   Fallback Response
    ↓
Continue Conversation
```

The conversation continues until the user enters one of the defined exit commands.

## Example Interaction

```text
User: Hello
Bot: Hello! How can I help you?

User: What is your name?
Bot: I am your chatbot.

User: Bye
Bot: Goodbye!
```
